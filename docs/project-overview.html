01

6단계로 완성한 가계부

입력 → 인식 → 분류 → 시각화 → 알림

입력 채널을 하나씩 늘려가며, 사람이 직접 정리하던 일을 AI와 자동화로 옮기는 순서로 설계했다.

1

카드문자 입력

카드 승인문자를 붙여넣으면 정규식으로 가맹점·금액·일시를 자동 추출. 여러 건 한 번에 붙여넣어도 자동으로 나눠 처리.

정규식 파싱SQLite 스키마
✓ 문자 복붙만으로 거래 등록
2

카카오페이 입력

송금 내역을 붙여넣으면 자동 파싱. 상대가 사람이라 가맹점 분류가 불가능한 특성을 반영해 소셜/네트워킹으로 고정 배정.

정규식 파싱고정 분류 규칙
✓ 송금 내역도 놓치지 않고 기록
3

영수증 업로드 & OCR

영수증 사진을 올리면 Claude Vision이 금액·가맹점·날짜를 읽어낸다. 키가 없거나 실패하면 수동 입력으로 자연스럽게 전환.

Claude Vision API폴백 설계
✓ 사진 한 장으로 영수증 등록
4

AI 자동 분류 & 학습

가맹점명을 Claude로 분류하고, 사용자가 재분류하면 그 가맹점 규칙을 학습해 다음부터는 규칙이 AI보다 먼저 적용된다.

Claude 프롬프트 설계규칙 학습(merchant_rules)
✓ 쓸수록 분류가 정확해짐
5

대시보드

최근 6개월 지출·수입 추이, 대분류별 지출, 소분류 TOP 10을 한 화면에서 확인. 카테고리 배색은 항상 같은 대분류가 같은 색을 갖도록 고정.

Plotly집계 쿼리라이트모드 배색
✓ 이번 달 소비가 한눈에
6

카카오 로그인 & 알림

카카오 OAuth2.0으로 로그인하고, '나에게 보내기'로 월간 리포트를 카카오톡으로 직접 받는다.

Kakao OAuth 2.0Talk Memo API
✓ 리포트가 카카오톡으로 도착
